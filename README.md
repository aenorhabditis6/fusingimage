# 溶光 · OC 融图台

把透明底（或白底、纯色底）的 OC 立绘放进任意背景，自动对齐亮度和色调，再加光源、轮廓光、投影和整体调色，让人物看起来本来就在那个场景里。

纯静态网页：`index.html` + `style.css` + `app.js`，没有依赖、没有构建步骤。所有计算都在浏览器里完成，图片不上传；没有用 Google Fonts 或 CDN，国内网络也能正常打开。

## 本地运行

```bash
python3 -m http.server 5178
```

然后打开 http://localhost:5178 。

## 功能

| 页 | 内容 |
|---|---|
| 素材 | 上传背景和人物；人物图没有透明底时自动抠掉纯色底；支持拖放、Ctrl/⌘+V 粘贴 |
| 光线 | 自动找光源或手动拖小太阳；8 种打光方式（自动、正面、顶光、背光、左右侧光、底光、在阴影里）；光色、强度、前后位置、照射范围；轮廓光、暗面压暗、暗面环境色、亮面光色；光晕、光束；地面投影、贴身暗晕 |
| 融合 | 亮度对齐、染环境色、饱和度对齐（按人物身后那块背景统计）；光包裹；脚下融进前景；边缘烟雾 |
| 人物 | 大小、旋转、翻转、脚踩到底；亮度 / 对比 / 饱和 / 冷暖；抠底容差、去贴纸白边、边缘收缩 |
| 调色 | 7 种风格预设；曝光、色温、对比、饱和、褪色、分离色调、柔光、暗角、颗粒 |

预览区可以切换「贴纸原样 / 融图后 / 看明暗 / 看颜色」，或按住「按住对比」临时看原样。导出按背景原尺寸（电脑端最长边 3200，手机端 2400）。

## 原理简述

1. **抠图**：取四条边的中位色当底色，从边缘做泛洪填充，边界一圈按色差算半透明，并做去底色污染。
2. **去白边**：从透明区域往里吃掉和外圈颜色接近的像素，深度有上限。
3. **颜色对齐**：统计人物身后背景的中间调、亮部、平均色、暗部色，生成一个 33³ 的 3D LUT 作用到人物上。
4. **打光**：把人物轮廓大半径模糊后取梯度，得到「鼓起来」的伪法线；按光源方向做明暗和双色渐变（暗面带环境色、亮面带光色），边缘再用小半径法线加轮廓光。
5. **合成**：贴身暗晕和投影（multiply）→ 人物 → 光包裹（模糊背景只留在人物内边缘一圈）→ 轮廓光（screen）→ 前景草叶、烟雾、光束、光晕。
6. **统一调色**：整张图过一个调色 LUT，再叠柔光、暗角、颗粒。

## 部署

任何静态托管都行，把这三个文件放上去就可以：

- GitHub Pages：建一个仓库，推上去后在 Settings → Pages 里选 main 分支根目录。
- Cloudflare Pages / Vercel / Netlify：直接导入仓库或拖文件夹上传，不需要构建命令。
- 想让国内访问更快，可以用腾讯云 COS、阿里云 OSS 的静态网站托管。
